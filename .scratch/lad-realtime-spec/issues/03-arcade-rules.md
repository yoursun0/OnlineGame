## Question

What are the canonical arcade rules for 小朋友落樓梯 (also known as falling-stairs / stair-drop browser games): lives or one-shot death, holes vs moving stairs, reaching the bottom vs survival score, collision, and any historical multiplayer?

Use primary or first-party sources where possible. This is a fallback so [What counts as winning a shared well](04-shared-well-outcome.md) is not blocked forever if the prototype is thin. Do not invent house rules.

## Answer

Canonical game is NAGI-P **NS-SHAFT** (HK 小朋友落樓梯 / TW 小朋友下樓梯 / CN 是男人就下100層). First-party 1.3J: **life gauge**, not one-shot — game over at 0 life **or** falling off the bottom. Arena is a **moving-platform shaft** with spikes, conveyor, jump pad, and rotating floors; gaps exist, but official text does not name “holes.” Score is **floors descended** (top 5); there is **no** official 100-floor / reach-the-bottom clear — “100層” is the Flash slogan. Collision documented: ceiling/floor spikes damage, miss-platform is instant death; wrap and player-push are **undocumented**. **Local 2P** is first-party from 1.3J (same well, P1 arrows / P2 Z·X, continue while either lives, 2P scores not recorded).
